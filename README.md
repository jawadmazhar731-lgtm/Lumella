# Lumella — Store Admin Dashboard

A dark-themed e-commerce admin dashboard for a small store owner. Sales, orders and products at a glance.

## Live Demo

https://jawad-lumelle.surge.sh

## Features

- **Home** — Today's revenue, orders and products overview with a revenue chart and top products list
- **Products** — Category cards and a full product table with stock and pricing
- **Analytics** — Revenue growth by channel and top regions
- **Orders** — Order list with status and totals
- **Customers** — Customer list with order history
- **Login / Sign Up** — Front-end only pages (in-memory session, no backend)

## Design

Calm, exact, a little warm: warm graphite surfaces, one gold accent, Manrope type. No gradients, no emoji icons — clean line icons throughout.

## Run Locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Tech

Single-file HTML, CSS and JavaScript. No build step, no dependencies to install.
